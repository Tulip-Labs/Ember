EMBER 3.0 — PERMANENT INSTALL
=============================

Run INSTALAR.bat ONCE. It removes the Ember you have installed now,
installs 3.0 in its place, and sets 3.0 as your permanent Windows
shell. From then on Ember simply starts with Windows — no installer
to run again, nothing to redo after a restart.

Your Ember settings survive: hidden apps and your chosen theme are
kept (they live in the registry, not in the program folder).

Steps:
1. Unzip everything into one folder (keep the files together).
2. Double-click INSTALAR.bat.
3. Say Yes to the restart at the end — after it, Ember 3.0 is your shell.

Ways back, always available:
- Inside Ember: power button (bottom right) -> Restore Windows Explorer.
- RESTAURAR-EXPLORER.bat: sets Explorer as the shell again (restart after).
- If Ember ever fails to start 3 times in a row, it restores Explorer
  by itself.
